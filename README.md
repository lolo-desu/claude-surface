# Claude Surface 0.10.2 开发版

为 SillyTavern 提供 Claude、Material Design、Adwaita 和 FlatDesign 的界面扩展。

| 分支 | 用途 | 当前版本 |
| --- | --- | --- |
| [`main`](https://github.com/lolo-desu/claude-surface/tree/main) | 主线，日常安装与更新使用 | 0.9.5 |
| [`codex/material-adwaita-swiss`](https://github.com/lolo-desu/claude-surface/tree/codex/material-adwaita-swiss) | 开发，后续功能与修复先在这里验证 | 0.10.2 |
| [`codex/legacy`](https://github.com/lolo-desu/claude-surface/tree/codex/legacy) | 遗产，保留升级前主线的 Claude 风格与行为 | 0.8.1 |

## 安装

0.10.2 hotfix：修复手机世界书页面能整体上下左右移动的问题。面板贴合导航栏下方的可视区域，消除内部容器外边距造成的横向溢出；打开时锁定页面根滚动并解除影响固定定位的根节点 3D 效果，条目在内部滚动。输入控件使用 16px 字号以避免 iOS 聚焦自动放大，可视区域缩小时面板跟随调整；保留手动缩放，关闭面板或回到桌面时恢复原行为。同时修复点击世界书下拉搜索框被原生逻辑误判为外部点击、导致面板关闭的问题，保留下拉框自身的选择和输入事件。

0.10.1 hotfix：修复扩展页“在扩展程序更新时通知”勾选标记覆盖面板、挡住其他按钮的问题。勾选框恢复自身定位；勾选、半选和单选图形使用控件尺寸，并禁止装饰层拦截点击。桌面原生面板在侧栏以外的可用区域居中，避免常驻侧栏挡住左侧内容。

0.10.0 开发版：四种风格分别完善勾选框、半选状态、单选按钮、即时设置开关、滑块、输入框与分段按钮，主题色同步作用于控件。保留原生输入行为、键盘焦点与禁用状态，尊重减少动态效果与强制高对比度偏好。

0.9.5 hotfix：修复 Material 设置分组的首尾圆角方向和单行分组形状，圆角由整个分组统一裁切；隐藏品牌项不再影响末行判断，同时修正 Material、Adwaita 分组底部多余的分隔线。

在 SillyTavern 中打开“扩展 → 安装扩展”，粘贴以下仓库 URL：

```text
https://github.com/lolo-desu/claude-surface
```

直接填写仓库 URL 会安装 `main` 主线。需要开发版或遗产版时，在安装框的“Branch or tag name／分支或标签名”分别填写 `codex/material-adwaita-swiss` 或 `codex/legacy`。已有安装可在扩展管理中切换分支，再刷新页面。三个分支是同一扩展的不同版本，选择一个使用即可。

安装完成后刷新页面即可使用，后续可通过酒馆的扩展管理更新。仓库根目录直接包含 `manifest.json`、`index.js` 和 `style.css`，无需构建或安装依赖。

启用时会导入并切换到所选风格的原生主题。切换前通过酒馆原生主题导入保存当前外观快照，包含尚未另存的自定义 CSS，不覆盖原主题。停用时恢复快照。选择其他原生主题时会自动停用 Surface 壳层，让所选主题接管；重新启用时会备份当前主题。只有旧版 Claude Base 的空 CSS 表会暂停生效，其他原生主题样式表保持启用。卸载前请先停用界面。

## 设计风格

主题设置提供 Claude、Material Design、Adwaita、FlatDesign 四种设计，默认保留 Claude。主题卡片只显示名称与预览。深色、浅色和跟随系统均可选择。

Material 使用分层色调、胶囊输入栏和柔和面板动效；Adwaita 使用居中标题、分组偏好和短促动效；FlatDesign 使用明确字阶、轻边界和快速动效，夜间主体为中性炭灰。所有动效遵循系统减少动态效果偏好，不动画聊天宽度或世界书条目高度。

控件随风格变化：Claude 使用细边勾选框和纤细滑块；Material 使用大圆角开关、粗轨道与竖条滑块把手、连接式分段按钮；Adwaita 使用白色圆形开关把手、凹入输入框与圆形滑块；FlatDesign 使用方形勾选框、方形开关和下划线分段按钮。设置中的即时开关只作用于本扩展的布尔偏好；原生和第三方的选择项保持勾选框，不替换节点、事件或数值。所有外观同样提供未选、选中、半选、禁用、键盘焦点状态；触屏不保留鼠标悬停效果。

Material 首页的静态柔光围绕问候语展开，范围不随页面高度拉长；柔光和细微抖色共用椭圆遮罩，在图层四周提前淡到透明，避免矩形截断。低亮度渐变与细微抖色用于减轻深色背景的色带，不使用持续动画或大面积模糊。

四种设计均可在“主题设置 → 背景与毛玻璃”调整界面透明度（0–100%）、界面毛玻璃（0–32px）、背景变暗（0–100%）与背景模糊（0–24px）。拖动实时预览并保存，切换设计、主题色及昼夜时保留这些偏好；“重置效果”只重置四个滑块，不更换背景图片。未显示背景图时，背景变暗与模糊控件暂时禁用，数值仍保留。界面透明度仅影响表面底色，文字和控件不会一起变淡；系统减少透明度偏好优先。

启用背景图后，图片延续到输入栏和底部工具区后方，输入框独立显示毛玻璃底色，移除外层实色矩形造成的截断。聊天区域增加随界面透明度变化的主题底色，斜体正文保持清晰；背景变暗和模糊只作用于图片层。背景模糊时为图片留出足够的边缘扩展，避免窗口四周出现模糊黑边。停用 Surface 后这些覆盖停止生效，保留原生背景图片及适配方式。

深浅色选项下方提供“主题色”，每种设计独立记忆：Claude 三套、Material 四套、Adwaita 四套、FlatDesign 三套。三种新增风格的侧栏、首页和可选启动屏统一显示 SillyTavern，采用各自原创几何图标。Claude 风格的自定义名称与图标偏好会保留，切回时恢复。

所有消息正文均不设置侧向头像列。极简模式的角色头像在底部信息行；头像和横幅模式在正文上方展示；用户头像放在名称与时间行中，不占气泡正文宽度。用户短句气泡按正文收窄并靠右，文字保持正常左对齐；姓名时间行不会撑宽气泡。编辑时恢复可用的编辑区域宽度。仅导入 CSS 的原生主题同样采用头像在上、正文另起一整行的布局。

三套标准主题 JSON 位于 `themes/Claude Surface Material.json`、`themes/Claude Surface Adwaita.json` 和 `themes/Claude Surface Swiss.json`，可直接导入原生主题列表。为兼容旧安装，FlatDesign 沿用原 Swiss 文件路径和设置标识；列表中显示为 SillyTavern FlatDesign，旧配色选择会保留。完整首页、侧栏与设置卡片需要扩展。

## 扩展兼容

- [Theme Companion](https://github.com/liangsheng-sys/SillyTavern-Theme-Companion)：启用后主题设置增加“伴侣”。选择该模式或使用伴侣的昼夜控件后，界面跟随其手动、系统和定时昼夜结果；本扩展手动选择系统、深色或浅色时独立生效。保留伴侣的样式表、主题目录与配置；使用其其他原生主题时让出界面控制权。
- [Chat Top Info Bar](https://github.com/SillyTavern/Extension-TopInfoBar)：保留搜索、聊天切换与原生按钮；手机两行排布，聊天历史和连接配置覆盖显示，不挤压消息宽度或抬高输入栏。
- [Quick Persona](https://github.com/SillyTavern/Extension-QuickPersona)：按钮与输入栏对齐，原生 Popper 菜单随主题配色，保留人设选择、默认/当前标记以及头像形状偏好。
- [Typing Indicator](https://github.com/SillyTavern/Extension-TypingIndicator)：提示保持在聊天区域内，跟随主题颜色与系统减少动态效果设置；显示、流式开关与生命周期由原扩展控制。

停用本界面后，上述样式覆盖停止生效，不修改这些扩展的源文件、配置或主题目录。

## 手动安装

手动安装时，将仓库克隆到 SillyTavern 的 `data/default-user/extensions/claude-surface/`。多用户实例请将 `default-user` 替换为对应用户目录。已有手动安装版本时，请先在酒馆中停用旧副本并备份，再替换为 Git 安装，避免同时加载两份扩展。

## 使用

- 左上角控制 Claude 风格侧栏：PC按钮切换固定/取消固定，切换功能和角色后保持常驻，状态会保存；移动端仍为展开/关闭。侧栏搜索和打开最近使用的角色，显示头像，同一角色的多个聊天不重复占行。
- 侧栏入口依次为：首页、预设、扩展程序、世界书、角色卡、更多。首页不常驻高亮。移动端侧栏占满屏幕，不叠加暗幕；展开时不会聚焦搜索框，主动点击搜索仍可正常输入。
- “角色卡”直接打开原生角色列表，保留搜索、排序、列表/网格、创建和导入等管理功能，控件采用线条图标和统一样式。点击角色直接进入聊天；自制角色选择页已移除。
- 右上角三个点的菜单依次为：Claude 首页、聊天记录、新建聊天、编辑角色世界书、编辑角色详情。世界书入口打开当前角色绑定的世界书；尚未绑定时进入原生绑定流程。
- “更多”展示全部九个顶层入口和主题设置，使用统一的线条图标。原生工具栏与原版首页开关集中在主题设置，不再重复出现在更多菜单中。PC 菜单紧邻入口弹出：顶部入口向下、输入栏入口向上。移动端采用底部面板，支持拖拽把手关闭。
- PC的预设覆盖在聊天左侧、角色卡列表覆盖在右侧，二者可同时打开；展开和收起不改变聊天区、消息排版及输入栏的位置或宽度。只有固定侧边栏会占用布局空间。各面板可单独关闭，选角后角色列表保持显示。其他原生面板继续从上方居中下拉。移动端原生面板为贴合顶栏、左右边缘和底部的完整页面，不使用浮动卡片。
- “显示原生菜单栏”单独保存开关状态；打开面板不改变这个偏好。原生图标点击保持toggle：同一按钮再次点击关闭，切换其他按钮时遵循原生面板逻辑。SVG子元素不会提前触发外部点击关闭；PC停靠使用可恢复的原生固定状态，不改写原版固定偏好。
- 主题设置中新增“输入栏紧凑模式”，把工具、输入框和发送区排在同一行；仍使用原生输入框和按钮，保留消息文本。“顶栏显示”提供四种模式：完全显示、滑动隐藏、点击显示、完全隐藏。滑动隐藏在主动向下浏览时收起，向上浏览或输入时显示，不因模型自动滚动触发；点击显示通过屏幕上沿的下箭头展开，点击页面其他位置收起；完全隐藏不保留这个箭头。原生下拉页面打开期间会临时显示顶栏；完全隐藏模式下也会临时显示原生菜单栏，关闭页面后恢复所选模式。原生菜单栏的独立开关继续控制平时是否显示图标行。旧版滑动隐藏偏好会自动迁移。紧凑模式默认关闭，顶栏默认完全显示。
- 输入框下方也可打开工具及 API 连接。输入框内的省略号为**完整原版聊天菜单**，旁边是**原版附件与扩展菜单**。
- 用户消息采用右对齐气泡，头像、名称和时间同处气泡上方的信息行，编辑和更多操作在下方；角色消息提供“极简／头像／横幅”三种样式，在主题设置中选择并保存。极简保留底部小头像；头像在正文上方显示较大的圆形头像；横幅使用角色原图在正文上方展示封面，上下边缘渐隐融入背景。三者均不挤占正文宽度，保留底部信息和切换回复控件。左右切换箭头使用相同字号及居中行框，计数单独占行，不依赖字体基线；保留原生节点及事件处理。继续使用 SillyTavern 的原生处理逻辑。
- 思维链采用简洁的星形图标标题、折叠箭头与细线正文；思考中显示轻微动效，遵循减少动态效果偏好。保留原生耗时、折叠、复制、编辑、保存和删除操作，不读取未返回的模型内容。
- 顶部房屋按钮返回 Claude 首页。首页可点击“最近聊天”或上滑查看最近聊天；侧栏的“最近使用”仍按角色呈现。
- “主题设置 → 原版首页与最近记录”开关选择首页版本，偏好会保存；开启后可使用原版欢迎页中的设置、固定聊天等功能。点击“Claude 首页”或“返回 Claude 首页”会关闭这个开关，切回 Claude 首页。
- 原生快速回复按钮采用紧凑圆角控件，支持自动换行和展开上下文菜单，保留原有命令行为。
- 预设滑块和数值框可直接调整，参数锁已移除；滑块说明和顶部帮助入口已收起。
- “主题设置”可修改侧栏名称，并将侧栏及首页标志切换为 Claude、ChatGPT、Gemini、DeepSeek 或自定义图片；图片在本机缩放为 128px PNG 并存入酒馆设置，不依赖外部图片服务。内置品牌标志来源与许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。还可选择深色、浅色或跟随系统，切换英文回复衬线字体，并启用 SillyTavern 背景图片。中文始终使用系统无衬线字体。手机触控界面额外提供“快速回复收起”：启用后仅在聚焦输入框时展开QR栏，操作QR按钮期间保持显示；PC始终显示原生已启用的QR栏。默认关闭此选项。
- 原版扩展设置中提供 Claude Surface 的启用开关。停用后恢复原版布局；卸载时删除本扩展目录即可。

## 实现边界

使用原版消息数据、输入框、发送按钮、设置面板及聊天 API。最近聊天从本地 `/api/chats/recent` 读取。没有替换模型后端，没有加入 API 密钥，不向外部服务发送遥测或对话。

字体使用本机 Georgia 与系统字体；不包含 Claude 的专有字体。页面标识、模型按钮和工具入口根据 SillyTavern 功能调整。本扩展为独立仿制，不是 Anthropic 官方产品。

同时覆盖原版面板中的标题、分节、输入框、下拉框、滑块、复选框及按钮，移除旧式渐变和阴影。头像固定为圆形，消息编辑沿用原版控件。提示词列表统一名称、操作与 Token 列。PC 世界书保留原生内部排布；移动端参考用户提供的“柏柏黑喵”主题布局，采用紧凑工具栏及条目卡片，位置、顺序、概率与操作始终可见，展开后显示关键词和正文，其他设置在“更多条目设置”中。切回 PC 时恢复原生字段位置。参考主题的字体及 CSS 未复制进发行包。

首页问候语和角色按钮使用同一排版容器，随窗口高度和文字换行自然排列。弹出面板限制动画溢出，焦点进入与返回不滚动背景页面，避免菜单入场时主界面短暂位移。动画遵循系统“减少动态效果”偏好。

聊天容器解除原生最大高度限制，顶栏收起时输入栏仍贴近窗口底部，阅读位置保持稳定。

输入框、文本区和选择框采用框内焦点描边，避免外轮廓被滚动容器裁切。

## 启动画面

URL 安装后首页、聊天和设置样式即可使用。最早期启动屏需要在 SillyTavern 加载扩展之前载入样式，因此是额外的可选步骤：在扩展目录运行以下命令，路径替换为酒馆根目录：

```powershell
powershell -File install-startup.ps1 -SillyTavernPath 'D:\SillyTavern'
```

该脚本只在 `public/index.html` 的 head 添加带标记的启动脚本引用，可重复执行。SillyTavern 更新后如覆盖该文件，可再次运行。移除时加 `-Remove`；停用扩展后，下次启动自动恢复原版启动屏。单独安装 CSS 主题不包含此启动集成。

当前实测 SillyTavern 1.19.0，并按 TauriTavern 的原生世界书模板及 CodeMirror 编辑器结构检查布局兼容性。移动端条目展开避免高度动画与编辑器初始化互相干扰，编辑器内容变化不会反复重排条目标题；PC 保留原生排布。检测到启用的 ST-BaiBai-Tools 时，优先由对方负责世界书布局、展开和提示词列表结构；本扩展只继承统一配色与字体，不再二次移动字段或接管条目展开。不更改 BaiBai 的设置。未安装或已停用该扩展时，使用 Claude Surface 自身布局。尚未在 iPhone Air 的 TauriTavern 应用内执行真机回归。未来版本若修改 DOM 或扩展 API，需重新验证。主题设置移除说明文案、重复的用户设置入口和右上角关闭按钮；点击遮罩、手机把手或按 Escape 收起。停用按钮单独放在左下方并采用偏红配色。扩展折叠标题采用有留白的纯色行，移动端扩展管理按钮分行排列；聊天标题左侧显示当前角色的小头像。

主题覆盖布局与配色；需要原版自由拖动布局时可停用本扩展。第三方扩展内容使用其原有控件，尚未逐个插件验证。

也可下载 [深色主题](themes/Claude%20Surface%20Dark.json) 或 [浅色主题](themes/Claude%20Surface%20Light.json)，通过原版用户设置导入，获得仅 CSS 的外观；完整首页与侧栏需本扩展。两种方式任选其一即可。

## 浏览器回归

`tests/controls.browser.mjs` 使用独立的 Chromium、WebKit 无头浏览器，在四种风格、深浅色和手机／窄桌面／宽桌面窗口下实际点击更新通知、扩展管理、安装按钮和设置折叠项，并检查开关、下拉框、滑块键盘输入以及面板与侧栏的边界。还检查五套原生 CSS 主题的勾选图形边界。测试拦截设置保存、主题保存及扩展变更请求，避免测试写入服务器偏好或安装／更新扩展。

需要本地 SillyTavern 实例和 Playwright 测试依赖及浏览器，运行 `node tests/controls.browser.mjs`；默认地址为 `http://127.0.0.1:8010`，可通过 `CU_TEST_URL` 指定。默认使用仓库的 CSS 验证修复，`CU_SERVER_CSS=1` 可检查实例已安装的样式。可通过 `CU_PLAYWRIGHT_MODULE`、`CU_CHROMIUM_EXECUTABLE`、`CU_WEBKIT_EXECUTABLE` 指定测试依赖和可执行文件。无头 WebKit 回归不等同于 iOS TauriTavern 真机验证。

`tests/world-info.browser.mjs` 在触摸手机上下文中检查四种风格、深浅色、320/393/430px 竖屏和 844px 横屏的世界书宽高、横向溢出、输入聚焦和内部滚动，并检查旧浮动坐标不会移动面板。Chromium 额外使用真实触摸事件滑动；Playwright 的移动 WebKit 不提供滚轮注入，内部滚动通过键盘事件检查。键盘收起／弹出通过模拟 VisualViewport 变化检查布局计算，另测手动缩放不会重排面板以及关闭／桌面切换后的清理。这些检查不等于 iOS 原生键盘和真机边缘回弹验证。运行方式和 Playwright 环境变量与控件回归相同。
